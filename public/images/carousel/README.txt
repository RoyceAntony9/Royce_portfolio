Skills & Recognition Carousel Custom Image Assets
=================================================

Please place your custom images in this folder. The application is configured to automatically read them from here without requiring any rebuild or code changes!

You can name your images:
1. `bhojanam.jpg` (or `.png`) — For the Bhojanam Ayurvedic App
2. `news.jpg` (or `.png`) — For the Daily News Highlights platform
3. `hackathon.jpg` (or `.png`) — For the Google Bit & Build Hackathon
4. `nurture.jpg` (or `.png`) — For the Nurture Aerospace UAV role
5. `rotaract.jpg` (or `.png`) — For the Rotaract Public Relations role

If any of these images are missing, the component will gracefully fall back to a high-quality, professional dark-blue themed Unsplash placeholder image.
